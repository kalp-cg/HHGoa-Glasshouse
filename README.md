# Glasshouse

Shows what an AI agent's on-chain x402 payments reveal about its owner, then makes them private with one switch.
Team 0xkalp · Hacker House Goa 2026. Start with `PLAYBOOK.md`, `CONTRACTS.md` and `AGENTS.md`.

## Run

Needs Node ≥ 22.12 and pnpm (version pinned in `package.json`; `corepack enable` picks it up).

```sh
pnpm install
pnpm test          # all Vitest suites
pnpm typecheck     # strict TypeScript, every package
pnpm demo:check    # every PLAYBOOK gate as PASS / FAIL / PENDING
pnpm --filter @glasshouse/web dev   # web app on http://localhost:3000
```

Copy `.env.example` to `.env` for anything that talks to TigerGraph, chains or sponsors. Never commit `.env`.

## Fixtures

`fixtures/` is generated by the seeded simulator in `packages/engine/src/simulate.ts` (seed 42):

| File | What |
|---|---|
| `ledger.seed42.json` / `ledger.seed42.shield.json` | `Ledger`: "Pays openly" and "Shield mode" worlds |
| `truth.seed42.json` / `truth.seed42.shield.json` | `GroundTruth`: tests only, never loaded into the graph or UI |
| `profile.open.json` / `profile.shield.json` | `ProfileFacts` for the demo person ("you") |
| `graph.open.json` / `graph.shield.json` | `GraphView` around the demo person |

Regenerate with `pnpm fixtures`. Same seed, same bytes.
